# 🧟 좀비 타워

용암이 차오르는 타워를 좀비를 뚫고 올라가는 **로블록스풍 3D 점프맵 서바이벌**. 아이패드(가로 화면) 터치 조작이 기본이고, PC 키보드로도 테스트할 수 있다.
Three.js + Vite + 순수 JavaScript. 에셋 파일 없이 전부 코드로 만든 박스 모델/효과음.

## 아이패드에서 바로 해보기 (개발 중)

1. PC에서 한 번만: `npm install`
2. 개발 서버 실행: `npm run dev`
3. 터미널에 나온 `Network: http://192.168.x.x:5173/` 주소를 **같은 Wi‑Fi의 아이패드 Safari**에서 열기
4. (선택) 공유 → **홈 화면에 추가** → 주소창 없는 전체화면 앱처럼 실행

코드를 고치면 아이패드 화면에 바로 반영된다. 점프 감각/용암 속도 같은 수치는 아이패드로 직접 플레이하며 조정하는 게 가장 정확하다.
`?debug=1` 을 주소 뒤에 붙이면 FPS·용암 간격이 왼쪽에 표시된다. (예: `http://192.168.x.x:5173/?debug=1`)

## 조작

| 터치(아이패드) | PC |
|---|---|
| 왼쪽 **십자키** — 이동(카메라 기준, 대각선 가능) | WASD / 방향키 |
| 오른쪽 **⤒ 점프** | Space |
| **⚔️ 공격** (누르고 있으면 연속) — 가까운 좀비를 자동 조준 | J |
| **무기 슬롯 1~3** 탭 = 무기 교체 | 1 / 2 / 3 |
| **💧 물대포** — 용암을 6초간 굳힘 | Q |
| 빈 화면 **드래그** = 시점 회전 (앞으로 갈 땐 자동 정렬) | 마우스 드래그 |

## 탑 구조 (층 테마)

속이 빈 탑 안쪽 벽(창문·횃불·기둥)을 따라 나선형으로 올라간다. 2개 층마다 분위기와 장애물이 바뀐다.

| 층 | 테마 | 특징 |
|---|---|---|
| 1~2 | 지하 감옥 | 벽돌 벽, 횃불, 컨베이어 발판, 불기둥 시작 |
| 3~4 | 고서 도서관 | 책장 벽, 회전 막대, 움직이는·무너지는 발판 |
| 5~6 | 기계 공장 | 철판·파이프 벽, 보스(5층), 깜빡이는 발판 |
| 7~8 | 흑요석 성 | 용암 균열 벽, 장애물 밀도 증가 |
| 9~10 | 하늘 신전 | 대리석·황금 벽, 보스(10층) |

- **도전 방**(넓은 발판): 회전 막대(점프로 넘기) / 불기둥(붉게 깜빡인 뒤 분출)
- **컨베이어**(계속 떠밀림), **깜빡이는 발판**(깜빡이면 곧 사라짐), **허공 코인**(점프 궤적을 따라 3개씩)

## 게임 규칙

- 안전구역(0~10)마다 **보물상자**(무기 획득), **대장간**(강화·장착 변경), 물대포 충전. 도착하면 체력 회복, 용암은 멈추고 아래로 내려감.
- 안전구역을 떠나 첫 발판을 밟으면 6초 뒤 용암이 올라온다. 용암에 닿으면 사망 → 마지막 체크포인트에서 부활(용암은 그 아래 10m로 리셋, 해당 구간 코인 10% 손실).
- 2층부터 **용암선에서 올라오는 좀비 떼**가 발판을 점프로 따라 올라온다.
- 5·10층은 보스 경기장(보스층 상자는 영웅 등급 이상 확정). 10층 안전구역에 도착하면 탈출 성공 → 더 어려운 새 타워(무기·코인 유지).
- 무기: 방망이(넉백) · 도끼(광역) · 채찍(긴 사거리·관통·둔화) · 권총/소총/샷건. 등급 일반/희귀/영웅/전설 + 강화 +10까지.

## 밸런스 조정

모든 수치는 `src/config/` 한 곳에 있다.

| 파일 | 내용 |
|---|---|
| `balance.js` | 물리(점프·속도), 타워 난이도 곡선, **용암 속도/지연/물대포**, 강화 비용, 상자 확률 |
| `weapons.js` | 무기별 공격력·공격 속도·사거리·넉백·등급 배율·특성 |
| `zombies.js` | 좀비 체력·공격력·속도·코인, 층별 등장 비율 |
| `themes.js` | 층 테마별 안개색·발판색, 회전 막대/불기둥 등장 확률 |

자주 만지는 값: `LAVA.speedBase / speedPerStage`(용암 속도), `LAVA.startGap`(출발 간격), `TOWER.gapRatioLow/High`(점프 간격 난이도), `ECON.*`(강화).
타워 생성기는 점프 물리값에서 "건널 수 있는 최대 거리"를 계산해 그 이내로만 발판을 놓으므로, 수치를 바꿔도 **항상 클리어 가능**하다(테스트가 보장).

## 테스트·빌드

```bash
npm test          # 단위 테스트 47개 (타워 생성기 클리어 가능성, 물리, 강화/확률, 용암 상태)
npm run build     # dist/ 생성 (정적 파일)
npm run preview   # 빌드 결과 확인
node scripts/make-icons.mjs   # 앱 아이콘 다시 생성
```

## 배포 (아이패드 어디서나 접속)

`dist/` 는 순수 정적 사이트라 Vercel / Netlify / GitHub Pages 어디든 올릴 수 있다. 배포 후 URL을 아이패드 Safari에서 열고 **홈 화면에 추가**하면 오프라인에서도 실행된다(서비스 워커).
저장 데이터(코인·무기·진행)는 브라우저 `localStorage` 에 있으므로 **홈 화면 앱으로 설치해서 쓰는 것을 권장**한다(iOS는 안 쓰는 사이트 데이터를 지울 수 있음).

## 알려진 한계 / 다음에 할 만한 것

- 실제 아이패드 실기 튜닝 필요: 점프 간격 난이도, 용암 속도, 코인 수입은 플레이 후 `config/` 에서 조정.
- 물대포는 현재 "용암 전체가 굳는" 방식. 분사한 부분만 식는 국소 방식으로 확장 가능.
- 아이패드는 진동 API가 없어 피격 피드백은 화면 흔들림·소리·붉은 화면으로 처리.
