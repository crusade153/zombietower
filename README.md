# ❄️ Frost Tower · 얼음 성채

아이패드 Safari에서 플레이하는 **3D 점프맵·액션 서바이벌**입니다. 기존의 둥근 장난감풍 캐릭터와 밝은 화면을 유지하며 얼음 성채를 올라 용암 군주와 싸웁니다.

**아이패드판은 웹 게임입니다.** PC에서 `npm run build` 후 `아이패드-서버.cmd`를 실행하고, 아이패드 Safari에서 표시된 주소를 여세요. 같은 네트워크의 접속 주소가 있어야 하며 PC와 서버를 켜 두어야 합니다. 외부에서 접속할 HTTPS 링크는 별도의 배포 또는 공개 연결이 필요합니다.

재화 증가·저렴한 강화·7등급·무한 탄약·클리어 층 이동·강화 외형·10층 최종 보스와 직전 세이브존을 반영했습니다. 태블릿은 해상도 상한 1.5배와 1024 그림자 지도를 사용하고 상황에 따라 해상도를 자동 조절합니다.

플레이 중에는 **One False Move** BGM이 반복 재생됩니다. 제공한 원본 MP3(4.32MB)를 전체 길이 약 3분 그대로 80kbps 스테레오 MP3(1.80MB)로 압축해 약 58% 줄였습니다. 타이틀에서는 음악을 다운로드하지 않으며 모험 시작 버튼으로 재생됩니다. 일시정지·타이틀·앱을 벗어난 동안에는 멈추고, 계속하기에서 이어집니다. 일시정지 메뉴에서 **BGM·효과음 볼륨을 따로 조절**할 수 있습니다. 무기별 휘두르기·발사·명중·처치 소리를 보강하고, 동시 타격의 소리 과부하를 줄였습니다.

타이틀과 플레이 화면 오른쪽 위의 **그래픽 · 현재/블록** 버튼으로 현재의 둥근 그래픽과 **초기 블록 그래픽**을 전환합니다. 초기 버전의 각진 캐릭터를 복원하고 발판·장식·벽·용암을 단순한 블록 스타일로 표시합니다. 일시정지 메뉴에서도 두 스타일을 선택할 수 있으며, 플레이 도중 전환해도 위치·체력·무기·적·진행 상태는 유지됩니다. 선택한 스타일과 음량은 다음 실행·새 모험에도 유지됩니다.

저장은 접속 주소별로 브라우저에 보관합니다. 주소를 바꾸기 전 일시정지 메뉴에서 **저장 파일 백업**을 선택하고, 새 주소의 타이틀에서 **저장 파일 가져오기**로 코인·무기·층 기록을 복원할 수 있습니다. 기존 4등급 저장도 자동 변환합니다.

Godot Windows 시제품은 `godot/` 폴더에 별도로 보관했습니다. [Godot README](godot/README.md)는 해당 시제품용 설명입니다.

## 아이패드에서 실행하기

1. PC에서 한 번만: `npm install`
2. 개발 서버 실행: `npm run dev`
3. 터미널에 나온 `Network: http://192.168.x.x:5173/` 주소를 **같은 Wi‑Fi의 아이패드 Safari**에서 열기
4. (선택) 공유 → **홈 화면에 추가** → 주소창 없는 전체화면 앱처럼 실행

코드를 고치면 아이패드 화면에 바로 반영된다. 점프 감각/용암 속도 같은 수치는 아이패드로 직접 플레이하며 조정하는 게 가장 정확하다.
`?debug=1` 을 주소 뒤에 붙이면 FPS·용암 간격이 왼쪽에 표시된다. (예: `http://192.168.x.x:5173/?debug=1`)

## 탑 구조 (층 테마)

속이 빈 탑 안쪽 벽(창문·횃불·기둥)을 따라 나선형으로 올라간다. 2개 층마다 분위기와 장애물이 바뀐다.

| 층 | 테마 | 특징 |
|---|---|---|
| 1~2 | 서리 성채 | 얼음 발판, 컨베이어, 불기둥 시작 |
| 3~4 | 빙하 요새 | 회전 막대, 움직이는·무너지는 발판 |
| 5~6 | 수정 성채 | 화산 수문장(5층), 깜빡이는 발판 |
| 7~8 | 눈보라 성 | 흑요석 기사·지옥불 집행자, 장애물 증가 |
| 9~10 | 빙왕좌 | 보스 직전 저장 구역, 최종 보스 이그니스 |

- **도전 방**(넓은 발판): 회전 막대(점프로 넘기) / 불기둥(붉게 깜빡인 뒤 분출)
- **컨베이어**(계속 떠밀림), **깜빡이는 발판**(깜빡이면 곧 사라짐), **허공 코인**(점프 궤적을 따라 3개씩)

## 게임 규칙

- 안전구역(0~10)마다 **보물상자**(무기 획득), **대장간**(강화·장착 변경), 물대포 충전. 도착하면 체력 회복, 용암은 멈추고 아래로 내려감.
- 안전구역을 떠나 첫 발판을 밟으면 6초 뒤 용암이 올라온다. 용암에 닿으면 사망 → 마지막 체크포인트에서 부활(용암은 그 아래 10m로 리셋, 해당 구간 코인 10% 손실).
- 1층부터 **용암선에서 올라오는 좀비 떼**가 발판을 점프로 따라 올라온다.
- 5·10층은 보스 경기장(보스층 상자는 신화 등급 이상 확정). 10층 최종 보스 직전에 저장하며, 보스를 처치하고 정상 안전구역에 도착하면 클리어 → 더 어려운 새 타워(무기·코인 유지).
- 무기: 방망이(넉백) · 도끼(광역) · 채찍(긴 사거리·관통·둔화) · 권총/소총/샷건(무한 탄약). 일반/레어/에픽/신화/전설/천상/무적의 7등급 + 강화 +10까지.
- **코인은 귀합니다.** 일반 무기 첫 강화 40코인, +10까지 약 2,200코인(무적 등급은 약 4,400). 1층 수입은 약 160코인이라 2~3단계 강화가 한계이고, 타워 한 바퀴로 무적 무기 2~3개를 최대 강화할 정도입니다. 경제 개편 이전 저장의 코인은 1/8로 환산됩니다. 무적 드롭률은 1층 7%부터 10층 28%까지 올라갑니다.
- **이동 능력** (대장간에서 코인으로 영구 해금): ⏫ **2단 점프**(250코인, 공중에서 한 번 더 · 기본 점프 2.4m → 최대 약 3.9m) · 💨 **대시**(450코인, 0.17초 순간 돌진 약 3m, 공중 1회·재사용 0.6초, 돌진 중엔 떨어지지 않음). 타워는 기본 점프만으로도 항상 클리어 가능하므로 능력은 시간 별·황금 망자 추격·위험 회피용 지름길이다. 수치는 `balance.js`의 `ABILITIES`.
- **차지 필살기**: 공격 버튼을 누르고 있으면(일반 공격은 계속) 버튼 테두리에 금색 게이지가 차고, 다 차서 빛날 때 손을 떼면 무기별 필살기가 나간다. 재충전 6초(흰 테두리). 🏏 홈런 스윙(360° 강타·좀비를 날림) · 🪓 회오리 베기(1.2초 회전·이동 가능) · 〰️ 끌어당기기(앞쪽 좀비를 한데 모음, 황금 망자도) · 🔫 정밀 연사(최대 6마리 동시 조준) · 🔫 탄막 난사(1.5초 초고속 연사) · 💥 관통 산탄(14발 관통). 필살기는 방패를 무시한다. 수치는 `balance.js`의 `CHARGE`와 `weapons.js`의 `special`.
- **층별 별 3개**: ⏱ 목표 시간 안에(발판 수×2초, 보스층 +50초) · 💔 피격 3회 이하 · 💰 공중 코인 80% 이상. 층을 도는 동안 위쪽 가운데에 진행 상황이 보이고, 안전구역에 도착하면 결과 카드가 뜹니다. 별마다 **처음 딸 때만** 보상(25+12×층 코인). 일시정지 → 시작 층 선택에서 층별 별·최고 기록을 확인하고, 다시 도전하면 그 타워의 좀비·공중 코인·회복 아이템이 되살아납니다.
- **좀비 변종**: 💣 **폭탄 망자**(2층~): 다가와 도화선을 켜고 자폭한다. 붉은 원이 다 차기 전에 피하거나 멀리서 처치하면, 그 자리에서 터져 주변 좀비까지 휩쓸어 연쇄·콤보가 된다(가까이서 터뜨리면 나도 일부 피해). 🛡 **방패 수비대**(3층~): 정면 공격의 85%를 막는다. 천천히 돌아서므로 옆·뒤로 돌아가거나 점프해서 위에서 치면 된다(폭발·화상은 방패 무시). 💰 **황금 망자**(2층~, 층마다 55%): 공격하지 않고 도망치며, 들킨 뒤 25초 안에 잡으면 큰 코인을 준다.
- **적이 더 많습니다.** 층마다 약 10~38마리(1층 10 → 10층 38)가 배치되고, 넓은 발판에는 두 마리씩 서 있습니다. 1층부터 용암선에서 좀비 떼가 더 자주·더 많이 올라옵니다(최대 10마리 동시). 대신 1마리당 코인은 0.75배라 한 바퀴 총수입은 이전과 비슷합니다.
- **보스 경기장 4곳**: 3층 **마그마 거인**(내려찍기) · 5층 **화산 수문장** · 7층 **역병 여왕**(멀면 산성탄 3발, 9초마다 졸개 3마리 소환·최대 6) · 10층 **용암 군주 이그니스**. 보스 경기장 층의 상자는 신화 이상 확정. 그 밖의 2층 이상(2·4·6·8·9층)에는 **망자 우두머리**(정예 미니 보스)가 뒤쪽 넓은 발판을 지킵니다. 보스를 만나면 경고가 뜨고 위쪽에 체력바가 표시됩니다.
- **일반 몬스터 추가**: 🦘 **도약 망자**(3층~, 3~8m 떨어진 곳에서 덮쳐 옴) · 🔮 **주술 망자**(4층~, 3.5초마다 주변 8m 좀비 체력 18% 회복·보스 제외 → 먼저 처치) · 🟢 **분열 망자**(5층~, 쓰러지면 꼬마 망자 둘로 갈라짐). 몬스터는 모두 17종입니다.
- 일시정지 메뉴에서 클리어한 층을 선택해 이동하거나 Godot 이식판용 저장 파일을 내보낼 수 있습니다.
- **손맛**: 명중 순간 짧은 히트스톱(처치·보스 처치는 더 길게), 10% 확률 **치명타**(2배 피해·노란 숫자·전용 효과음).
- **킬 콤보**: 3초 안에 연속 처치하면 콤보가 쌓이고 5·10·20콤보에서 코인 ×1.5·×2·×3(보스 제외). 사망하거나 안전구역에서 다시 시작하면 초기화.
- **아슬아슬 보너스**: 사라지기 0.25초 전 무너지는/깜빡이는 발판에서 점프, 회전 막대를 간발로 뛰어넘기, 발밑 1m까지 차오른 용암에서 5m 이상 탈출(보상 2배) 시 코인 보너스.

## 밸런스 조정

모든 수치는 `src/config/` 한 곳에 있다.

| 파일 | 내용 |
|---|---|
| `balance.js` | 물리(점프·속도), 타워 난이도 곡선, **용암 속도/지연/물대포**, 강화 비용, 상자 확률, `THRILL`(치명타·히트스톱·콤보·아슬아슬 보너스) |
| `weapons.js` | 무기별 공격력·공격 속도·사거리·넉백·등급 배율·특성 |
| `zombies.js` | 좀비 체력·공격력·속도·코인, 층별 등장 비율 |
| `themes.js` | 층 테마별 안개색·발판색, 회전 막대/불기둥 등장 확률 |

자주 만지는 값: `LAVA.speedBase / speedPerStage`(용암 속도), `LAVA.startGap`(출발 간격), `TOWER.gapRatioLow/High`(점프 간격 난이도), `ECON.*`(강화).
타워 생성기는 점프 물리값에서 "건널 수 있는 최대 거리"를 계산해 그 이내로만 발판을 놓으므로, 수치를 바꿔도 **항상 클리어 가능**하다(테스트가 보장).

```bash

npm run godot:data           # Godot용 타워·밸런스·무기 모델 다시 내보내기
```

그래픽과 UI 검증은 Playwright로 실제 브라우저에서 실행한다. 처음 한 번 `npx playwright install chromium`으로 브라우저를 준비한 후, 개발 서버를 켠 상태에서 `npm run test:visual`을 실행한다. 시작 화면 애니메이션의 픽셀 변화, PC 키보드와 터치 점프, 공격, 일시정지, 보물상자와 대장간, 다섯 층 테마, 휴대폰/태블릿 배치를 확인한다. 스크린샷과 검증 결과는 `artifacts/visual-checks/`에 저장된다.

## 배포 (아이패드 어디서나 접속)

`dist/` 는 순수 정적 사이트라 Vercel / Netlify / GitHub Pages 어디든 올릴 수 있다. 배포 후 URL을 아이패드 Safari에서 열고 **홈 화면에 추가**하면 오프라인에서도 실행된다(서비스 워커).
저장 데이터(코인·무기·진행)는 브라우저 `localStorage` 에 있으므로 **홈 화면 앱으로 설치해서 쓰는 것을 권장**한다(iOS는 안 쓰는 사이트 데이터를 지울 수 있음).

## 알려진 한계 / 다음에 할 만한 것

- 실제 아이패드 실기 튜닝 필요: 점프 간격 난이도, 용암 속도, 코인 수입은 플레이 후 `config/` 에서 조정.
- 물대포는 현재 "용암 전체가 굳는" 방식. 분사한 부분만 식는 국소 방식으로 확장 가능.
- 아이패드는 진동 API가 없어 피격 피드백은 화면 흔들림·소리·붉은 화면으로 처리.
