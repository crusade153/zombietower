# Frost Tower · 얼음 성채

Godot 4.7.2로 이식한 독립 실행형 3D 게임입니다. Windows 실행 파일은 `builds/FrostTower.exe`이며 저장 데이터는 Windows 사용자 폴더에 저장합니다.

## 실행과 편집

- 프로젝트 루트의 `플레이-Godot.cmd`를 더블클릭하면 게임이 실행됩니다.
- `편집-Godot.cmd`를 더블클릭하면 Godot 편집기로 프로젝트를 엽니다. F6 또는 F5로 실행할 수 있습니다.
- `builds/FrostTower.exe`는 엔진을 따로 설치하지 않고 실행할 수 있습니다. 다른 PC로 옮길 때 같은 폴더의 라이선스 파일도 함께 복사하세요.
- GPU 드라이버가 Vulkan을 지원하지 않으면 `FrostTower.exe --rendering-method gl_compatibility`로 실행할 수 있습니다.

현재 검증·패키징한 플랫폼은 Windows입니다. 터치 조작은 포함되어 있지만 iPad/iOS 설치 파일과 실기 검증은 이번 빌드에 포함하지 않았습니다.

## 반영한 게임 규칙

- 적 처치 코인은 기존의 6배, 공중 코인은 10배입니다. 최초 층 클리어 보상은 1층 200코인부터 10층 650코인까지입니다.
- 일반 무기 첫 강화는 8코인이고 비용은 레벨마다 1.22배 증가합니다. 최대 +10까지 강화할 수 있습니다.
- 일반 / 레어 / 에픽 / 신화 / 전설 / 천상 / 무적의 7등급입니다. 무적 등급 확률은 1층 7%, 10층 28%입니다. 5·10층 상자는 신화 이상입니다.
- 권총·소총·샷건에 탄약 제한이나 재장전이 없습니다.
- 타이틀과 일시정지 메뉴에서 이미 클리어한 층으로 이동할 수 있습니다. 코인·무기와 최고 기록은 유지되며 층 보상·상자는 중복 지급하지 않습니다.
- 무기는 +1 강철 보강, +4 룬, +7 플라즈마, +10 황금 외형으로 바뀝니다. 6종 무기별 5단계 모델을 포함합니다.
- 얼음 성채에는 움직이는·무너지는·깜빡이는 발판, 컨베이어, 회전 막대, 불기둥, 상승하는 용암과 추격 몬스터가 있습니다.
- 상층에는 흑요석 기사·지옥불 집행자 등 정예 몬스터가 등장합니다. 5층 화산 수문장, 10층 용암 군주 이그니스와 전투합니다.
- 최종 보스 직전 안전구역에서 자동 저장·체력 회복·강화가 가능합니다. 사망하면 이곳에서 재도전하며 보스 체력이 초기화됩니다. 보스를 처치해야 정상 클리어가 인정됩니다.
- 이그니스는 체력 50% 이하에서 2단계에 들어가 화염탄과 충격파를 더 빠르게 사용합니다.
- 클리어 후 무기·코인을 유지한 채 더 어려운 새 타워를 시작할 수 있습니다.

## 그래픽과 데이터

Godot의 Forward+ 렌더러, 실시간 그림자, SSAO, 체적 안개, 발광, GPU 눈·불티 파티클을 사용합니다. Kenney의 애니메이션 캐릭터와 건축 모델을 가져오고 얼음·용암·흑요석 재질을 추가했습니다.

현재 네 가지 완전한 10층 배치를 포함하며 새 모험에서 그중 하나를 선택합니다. 원본 JavaScript 생성기의 점프 가능성 검사를 통과한 배치를 `data/towers.json`으로 내보냅니다. 무한한 새 시드를 Godot 실행 중에 생성하는 기능은 아직 이식하지 않았습니다.

원본 브라우저 버전은 일시정지 메뉴의 **Godot 이식판용 저장 파일 내보내기**로 JSON을 저장할 수 있습니다. 이식판 타이틀의 **웹 버전 저장 파일 가져오기**에서 선택하면 무기·코인·층 기록을 이전합니다. 기존 4등급 저장의 전설 무기를 새 전설 등급으로 변환하고 탄약 제한을 제거합니다. 원본 시드가 네 배치에 없으면 기본 배치로 이어집니다.

## 개발·검증

원본 수치를 바꾼 뒤 프로젝트 루트에서 `npm run godot:data`를 실행하면 타워·밸런스와 무기 GLB 모델을 다시 내보냅니다. Godot 편집기에서 가져오기 완료 후 실행하세요.

```powershell
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --editor --import
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path godot -- --verify
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot -- --capture
.tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --editor --export-release "Windows Desktop" "builds/FrostTower.exe"
```

검증은 네 타워의 보스 직전 저장 구역, 실제 물리 이동·키보드 점프·총알 충돌과 연속 발사, 7등급·강화, 저장 이전, 잠긴 층, 보스 2단계·부활·최종 클리어를 확인합니다. 캡처는 실제 렌더링 결과를 `artifacts/`에 저장하고 테스트 저장을 남기지 않습니다.
